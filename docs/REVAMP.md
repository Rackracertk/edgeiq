# EDGEIQ interface refresh
The Script is a public-data matchup briefing. It does not claim private sources or a predictive model. It uses only a recent published slate and current injury checks, and explicitly labels unavailable data.
Team filtering uses a league-specific directory (all 30 NBA, 32 NFL teams), supports full names and nicknames, and distinguishes no report from cleared to play.
Daily research filters include team, player, evidence ranking, sample ranking and optional one-card-per-player. Reference thresholds are not live sportsbook offers.
Halftime live filtering includes phase, team/player names, tracked lines in session storage and required pace to cross a user-entered line. No claim of live sportsbook prices.
Billing remains in its existing gated configuration. Before collecting subscriptions, validate the production checkout, webhook, subscription entitlement, data redistribution rights, feed uptime, mobile QA and customer cancellation.
