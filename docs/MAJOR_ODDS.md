# Multi-sport odds snapshot
The manual GitHub Actions workflow on main supports ALL, NBA, NFL, MLB, NHL, NCAAF, NCAAB, WNBA, SOCCER, TENNIS and MMA. The provider sports endpoint discovers active competitions. Featured game markets work when the provider offers them; supported player props are fetched event-by-event for seven team sport groups and domestic soccer leagues. Tennis and MMA primarily use game markets; no unsupported player prop is inferred. The slip builder remains player-prop-only.
Select Both, Lines or Props; optional team filter; default 30-credit cap (maximum 60), with 3 core player markets or up to 8 expanded per event. All modes require explicit display rights confirmation. League-wide moneylines first, round-robin event props next, spreads/totals if budget remains. Use Lines for wide game-market coverage and Props for deeper event coverage. Actual usage depends on returned markets. The server-only key is never exposed. Existing fresh snapshots from other matchups are preserved. Current quote freshness remains 15 minutes.
The workflow is manual and does not automatically spend credits. 500 monthly credits cannot cover all games and all props continuously. Browser refresh rereads the published snapshot, not the provider. GitHub build/deploy latency and provider availability can affect freshness. Provider terms: https://the-odds-api.com/terms-and-conditions.html.
