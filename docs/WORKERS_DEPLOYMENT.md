# Existing Cloudflare Worker deployment
The existing dashboard service is named edgeiq. Its production Git branch is edgeiq-launch-foundation-2026. Keep the connected repository Rackracertk/edgeiq, root /, build command npm run build and deploy command npx wrangler deploy. The checked-in wrangler.jsonc explicitly publishes dist as SPA static assets. Existing domain, DNS, secrets and API token should be managed in the existing Cloudflare project; no routes or credentials are declared in the repository.
After a successful deployment, visit the production domain's /build-info.json and compare commit with the deployed Git revision. This is generated from git HEAD in npm postbuild, not the source data snapshot date. Build success alone is not deployment success. Check Cloudflare Deployments and the Domains tab if a different version appears. No paid subscriptions are enabled by this deployment change.
