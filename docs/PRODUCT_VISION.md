# EDGEIQ product direction (current)
No standalone Script, workspace or Daily Cheat Sheet. Five primary destinations: Home, Player Props, Game Lines, Live Edge, Injuries. All ten sports remain selectable; NBA/NFL full historical player browsers, other sports matchup-based recorded player data when available. Home cards open Game Lines directly. Game Lines includes fresh verified sportsbook snapshots, optional slip research and recent matchup evidence. Keep the approved charcoal player cards, gold/green/black styling and optional search. No fabricated odds, predictions or data.
## Membership
Free beta stays default. Planned full-access membership $4.99/week, $12.99/month, $99.99/year. Optional sign-in and interest list; no checkout activated. VITE_MEMBERSHIP_PREVIEW is a frontend-only staging switch, off by default. It checks the authenticated user's own subscription record using existing RLS, and blocks research screens in preview when not active/trialing and unexpired. This is NOT a secure paywall: public static JSON assets and direct public-source requests remain accessible. Before paid launch, move protected data behind authenticated server endpoints, enforce entitlement server-side, remove public premium data assets, verify Stripe live price IDs/webhook/checkout and cancellation, test auth/RLS, and obtain display rights. Do not turn on paid access solely by enabling this flag.
## Priorities
Data quality first, then usability, then expansion. Keep quota-limited odds publisher and existing data workflows. Publish transparent accuracy and data limitations; no guaranteed outcomes. Verify actual production domain after builds.
