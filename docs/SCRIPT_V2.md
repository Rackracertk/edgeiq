# Script v2 implementation and coverage
Public fixture navigator: ten sports; ESPN public scoreboard is an unofficial research preview, not a commercial license. Tennis and MMA require two-participant records from the source; tournament coverage may be incomplete. Soccer leagues are explicitly enumerated. Five-sport existing publications provide observed team form and only fresh provider quotes. Existing NBA/NFL briefing remains accessible for compatibility.
Premium endpoint script-intelligence authenticates the user with Supabase Auth and checks the server-managed subscription row (active or trialing and unexpired). All new premium reports originate from service-role-only edgeiq_script_cache; the browser cannot read that table. Public data already available in other EDGEIQ features remains public. No Stripe checkout/webhook changes.
script-refresh is protected with existing RESEARCH_REFRESH_SECRET and requires SPORTS_LICENSE_APPROVED=true. Configure SCRIPT_DATA_FEED_NBA, NFL, MLB, NHL, NCAAF, NCAAB, WNBA, SOCCER, TENNIS, MMA as separate HTTPS URLs for a normalized provider adapter; SPORTS_DATA_API_KEY and SPORTS_DATA_SOURCE_LABEL remain server-side. Each returns a JSON array of Snapshot records defined in _shared/script-model.ts, stable IDs matching the public fixture IDs and provider timestamps. Schedule calls using the trusted scheduler; no provider key or data rights assumed. Do not enable billing before commercial permissions and provider coverage are verified.
Model: observed scoring baseline (mean of team scoring and opponent allowance, at least five games), historical L10 player mean, separate observed split rates, score evidence components, strict timestamp deduplication, and walk-forward baseline MAE. No probability calibration, proprietary win probability, pace forecasts, injury usage redistribution or blowout probability. No immutable forecast ledger, verified phase forecasts or measured market correlations. Tennis/MMA score baselines intentionally withheld. Snapshot freshness 6h, quotes 15m, live 2m, injuries 15m. Missing source data never converted to zero.
Market categories are visible only for actual fresh quotes; the separately labeled catalog is a coverage checklist, not a listing of offered markets. Provider adapter must supply each verified market and stable player ID. Platform support (Hard Rock, DraftKings, FanDuel, BetMGM, Caesars, bet365, Fanatics, BetRivers, PrizePicks, Underdog, Kalshi) is not claimed without actual quotes and contractual rights. No full market equivalence adapter, full player headshots, lineup/weather model, or cross-feature automatic pregame-vs-halftime comparison yet. Existing live, injury, daily, markets and research features are unchanged; navigation connects them.
Before launch: provider adapter contract, secure scheduler, commercial licenses, representative fixtures per sport, production build and mobile/desktop/browser QA, anonymous/expired/active auth tests with legitimate test identities, Stripe sandbox/live configuration and cancellation, calibration/backtesting on season-complete held-out data, performance/load testing and sportsbook market equivalence verification.
